# Перенос шахматной программы «Каисса» с М-20 на БЭСМ-6

## Исходные данные

- **Программа**: `/home/azizz/Yandex.Disk/besm6-new/m20/kaissa/kaissa.m20`
- **Размер**: 1700 слов (45 бит)
- **Архитектура**: М-20 (1959 год, 4096 слов ОЗУ, 45 бит)
- **Документация**: `/home/azizz/besm6.github.io/doc/М-20-Каисса.pdf` (133 страницы)

## Архитектурные различия

| Параметр | М-20 | БЭСМ-6 |
|----------|------|--------|
| Разрядность слова | 45 бит | 48 бит |
| Команд в слове | 1 | 2 (по 24 бита) |
| Адресное пространство | 4096 слов (12 бит) | 32768 слов (15 бит) |
| Регистр адреса | РА (специальный) | M1-M17 (индекс-регистры) |
| Признак результата | Ω (отдельный триггер) | Нет (через условные переходы) |
| Формат float | TAG(1)+SIGN(1)+EXP(6)+MANT(36) | SIGN(1)+EXP(5)+MANT(41) |

## Соответствие команд

| М-20 | БЭСМ-6 | Комментарий |
|------|--------|-------------|
| п (пересылка) | xta + atx | 2 команды |
| со/сон (искл. или) | xta + aex + atx | + установка Ω |
| и | xta + aax + atx | + установка Ω |
| или | xta + aox + atx | + установка Ω |
| см/вм/ск/вк | xta + arx/x-a + atx | адресная арифметика |
| сдма/сдмп/сдса/сдсп | xta + wtc + atx | сдвиги |
| цс/цв/цсд | xta + arx/x-a + atx | циклические |
| пв/дпб | vjm | вызов подпрограммы |
| пе/пу | u1a/uza (по Ω) | условные переходы |
| пб | uj | безусловный переход |
| стоп | stop | останов |
| с/в/ва/у/д/к | xta + a+x/a-x/a*x/a/x + atx | арифметика |
| счп/ввод/МА/МБ | заглушки | ввод-вывод |

## Эмуляция регистров М-20

| М-20 | БЭСМ-6 | Назначение |
|------|--------|------------|
| РР | ACC | Регистр результата |
| РА | M[1] | Регистр адреса |
| Ω | M[2] | Признак результата (0/1) |
| РМР | M[3] | Младшие разряды произведения |
| - | M[4] | Временный регистр T |
| - | M[5] | Временный регистр T2 |

## Ограничения

1. **Ввод-вывод**: команды М-20 для перфокарт/АЦПУ не реализованы (заглушки).
2. **Точность float**: конвертация 36-битной мантиссы М-20 в 41-битную БЭСМ-6 с потерей точности.
3. **Сдвиги**: используется вспомогательная ячейка T_TMP для хранения сдвига.
4. **Ω**: эмулируется через индекс-регистр M[2] и условные переходы.
