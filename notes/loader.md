# Загрузчик Дубны: рецепт модуля (проверено опытами probe2/probe2c и записью 04.11.2026)

1. Формула каталога: длина загрузки = cmd + const + **bss** (ПАМ - это bss,
   НЕ data!). Ошибка длины -> «ИСПОРЧЕНА ПОДПРОГРАММА» и порча памяти.
   Именно это ломало записи 02-03.11: объект DRAKON писался без разделов
   const/bss (392 слова кода), а в записи каталога стояло 392 вместо 943.
2. Образ модуля: [заголовок 3 слова][cmd][const][set][имя][sym][long];
   w2 = cmd | bss<<15 | const<<30; set у KLAIDA пуст - обращения к общим
   блокам через МОДА релоаций не требуют.
3. Запись каталога (48 бит): дата - биты 47..26 (младшие 2 бита поля -
   верх длины), длина загрузки×8 - биты 25..12, оверлей - биты 11..0.
   Длина×8 > 4095 заходит в поле даты (SCHEMA: 521×8=0o10110 -> в поле
   0o110, у даты младшие 2 бита 01; SPAUD: 1643×8=0o31470 -> поле 0o1530).
   Запись = (дата<<24) | (длина×8<<12) - корректно при любой длине, если
   младшие 2 бита даты нулевые (у всех записей так).
4. Запись каталога нового модуля - В КОНЕЦ каталога (после завершателя
   не раньше): вставка в НАЧАЛО сдвигает нумерацию входов личной
   библиотеки, на которую ссылаются все модули, и ломает загрузку.
5. sym-элемент: (0o4000+X)<<24 | C<<12 | D (36 бит, старшие 12 нулевые).
   Семантика (сверено с sym-разделами ONEPLA/KLAIDA/START и с картой
   загрузки - записи ONEPLA идентичны в 2248- и 2348-копиях):
   - C=0      : X - номер символа СВОЕГО модуля, значение = символ X + D
                (INS24 = символ 1 (INS) + 24);
   - C=0o6700 : X - номер входа ЛИЧНОЙ библиотеки, значение = вход X + D
                слов (GETSTR = (37, 0o6700, 3) - так же ссылаются
                ONEPLA и STAATP; GETSTR в карте загрузки - 42103);
   - C=0o6300 : X - номер входа ПОСТОЯННОЙ библиотеки монитора
                (FT571/FT002/FT003 = (13/10/11, 6300, 0) из KLAIDA;
                WRIKOR/ENDKOR/GETSTR монитора у ONEPLA = 32/28/40);
   - C=1,2,7  : служебные способы START/ENDKOR (общие блоки монитора).
   Таблица DRAKON: INS=(12,6700,27) - как у самой KLAIDA; INS24=(1,0,24);
   GETSTR=(37,6700,3).  Таблица входов (оглавление РВС, слова 2048..3148
   образа 2248) загрузчику личной библиотеки НЕ нужна: чистый том 2348
   несёт каталог + модули подряд, и это работает.
6. Протокол WRIKOR: три параметра по ссылке (адрес текста, число слов,
   число знаков); сопрограмма требует живого контекста задачи SCHEMA.
   То же для GETSTR: автономный *main drakon грузится чисто, но падает
   на рантайме - полная среда модуля только внутри задачи СИПРОДа.
