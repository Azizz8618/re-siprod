# Диагностика Мадлен-объекта DRAKON (сессия 04.11.2026, ч.2)

## Что установлено

### 1. Формат образа диска dispak
Файл тома = записи zone_t по 8264 байта: 8 контрольных слов uint64 +
1024 слова uint64 **little-endian**; слово БЭСМ-6 = младшие 6 байт в
**обратном** порядке байт, тег свёртки - байт 6.  Зона монитора Z =
запись файла Z+4 (ZONE_OFFSET).  Прежние чтения (в т.ч. в коммите
268d8cd) были байт-реверснуты: тег 0x100 читался как слово 0o400.
Правильный читатель: `scripts/vol_diff_zones.py::read_zone`.

### 2. Где лежит объект МАДЛЕН
Компиляция `compile_drakon_full.py` (*LIBRA:2 + *TO PERSO:402600)
пишет библиотеку МАДЛЕН на **зоны монитора 0o2576-0o2601** (1406-1409):
- зона 1406: оглавление (слово 656 = 'DRAKON', 657 = запись, 659 =
  завершитель 0o7777...77);
- зона 1408: [текст 642-651][шапка 652-654][команды 655-923 = 269 слов
  (0o415)][данные 924-1018 = 95 слов (0o137)][имя 'DRAKON' 1019]
  [sym 1020-1023];
- зона 1409: [sym 0-24][long-имена 25-48 = 24 слова].

### 3. Формат слов объекта = слова Дубны
- команды: обычные 48-битные слова БЕМШ, 2 команды на слово; первое
  слово 0o7244000103040404 = [М16,VTM,1 | ПБ,404] - побайтово та же
  структура, что у работающего SCHEMA из siprod.bin;
- перемещаемые адреса: бит 14 адресного поля (0o4000 в 12-битном
  счёте, 0o40000 в 15-битном) + номер идентификатора в младших битах;
- данные: тег 0o64 в старших разрядах слова - **как у SCHEMA** (это
  часть формата Дубны, а не «упаковка Мадлен»).

### 4. Семантика идентификаторов (главный результат)
Пронумерованы по первому употреблению в коде:
- **1-20 - общие блоки** в порядке LC-объявлений (*BLO*=1, *RUSIS*=2,
  *INS*=3, … *REGIM*=16, … *FIN*=20);
- **21-24 - подпрограммы** (ENDKOR=21, WRIKOR=22, GETSTR=23, START=24)
  - совпадает с long-секцией (24 имени) и с ПВ-ссылками кода:
    ПВ 0o25×19 (ENDKOR), 0o26×19 (WRIKOR), 0o27×1 (GETSTR), 0o30×1
    (START);
- **25+ - внутренние метки** (в коде ссылки 0o31-0o37, 0o40-0o46).

Проверка: ссылки 0o2/*RUSIS*, 0o3/*INS*, 0o16/*REGIM*, 0o20/*FIN*,
0o21/*FOP*, 0o22/*RPT*, 0o23/*GOT* - точные попадания в общие блоки.

### 5. Почему загрузчик Дубны бракует модуль
sym-записи Мадлен-объекта (29 шт.) имеют базы 0o47-0o52, 0o64-0o72 -
**не совпадают** с идентификаторами кода (1-24, 25+).  Это внутренний
формат настройщика Мадлен-рантайма, а не формат Дубны.  Загрузчик
печатает «ИСПОРЧЕНА ПОДПРОГРАММА» и **не кладёт модуль в память**
(проверено дампом 01000-01617: кода модуля там нет), после чего *MAIN
выполняет служебный блок задачи на 01000 и падает в «Неизвестная ош.».

Заодно доказано: **БЕМШ-вариант (drakon.be) под *MAIN падает так же**
(прогон с проверенной библиотекой disk2348/lib.bin, дамп памяти) -
претендовавший «чистый возврат» был просто выходом после аварии.
Реальная среда обоих модулей - запуск внутри СИПРОДа (*main schema).

### 6. Рецепт загрузки двух библиотек (был сломан - найден)
3932 дес. = 0o7534, а не 0o7474.  Карта должна совпадать с зоной
besmtool: `besmtool write --start=3932` ↔ `*perso:677534`.
С совпадающими зонами обе библиотеки грузятся чисто:
`*perso:677534` → «02.10.81 M1», `*perso:672576,cont`/`672600,cont` →
«LIBRARY OT …».

## Что осталось (следующая сессия)
Пересобрать sym-секцию в формате Дубны:
1. 4 записи подпрограмм: (0o4000+X, 0o6700, позиция-в-каталоге),
   X = 21..24; позиции в каталоге siprod.bin: ENDKOR=81, WRIKOR=82,
   GETSTR=37, START=80 (1-based; при вставке DRAKON в начало каталога
   проверть базу отсчёта - БЕМШ-вариант использовал GETSTR=37).
2. Записи общих блоков: (0o4000+X, 0, смещение) - взять из Мадлен-записей
   с C=0 (X=3: смещения 1,2,3,24,25,26; X=16: смещение 1).
3. Записи внутренних меток: (0o4000+X, 0o6700, словосмещение метки) -
   смещения взять из dtran-текста (*NNNNB), соответствие X↔метка - по
   порядку первого употребления в коде (порядок ПБ-ссылок).
4. Вставить в siprod.bin (как в scripts/build_lib_madlen.py), записать
   на зону 695, прогнать *main drakon со схемой.

Инструменты сессии:
- `scripts/vol_diff_zones.py`  - корректное сравнение образов (LE);
- `scripts/match_dtran_obj.py` - чтение зон тома, disbesm6-обвязка;
- `scripts/build_lib_madlen.py` - сборка библиотеки с Мадлен-объектом;
- `scripts/dump_perso_obj.py`  - снятие зон тома в слова;
- `scripts/perso_probe.py`     - пробы загрузки библиотек с зоны.
