# СИПРОД: рабочие заметки по управляющим последовательностям

Рабочий журнал экспериментов в порядке их проведения.  Сводный справочник —
`SIPROD.md`; при расхождении верен он (ранние записи ниже местами уточнены там).
Эксперименты: `tests/siprod/frag.sh 'строка' ... | tests/siprod/measure.py`,
трассировка ветвей: `tools/siprod_probe.py`.

## Верхний уровень (SCHEMA)

Входной поток после `*EXECUTE` — последовательность блоков. Ключевое слово блока
сравнивается с таблицей `SCHEMA` /0747B (`*BLO*` = номер):

| N | ключ  | обработчик                         |
|---|-------|------------------------------------|
| 1 | `*HCH`| оверлей `WRITEH` (через `LOADGO`)  |
| 2 | `*IPO`| оверлей `WRIIPO`                   |
| 3 | `*NOT`| оверлей `NOTFOR`                   |
| 4 | `*RED`| `REDTXT` → `SPAUD`                 |
| 5 | `*SUB`| оверлей `PAPAPR`                   |
| 6 | `*END`| конец                              |
| 7 | `*REP`| ?                                  |

Иное ключевое слово — ошибка 100 (`KLAIDA`).

## Режим *RED (SPAUD)

`SCAN` классифицирует символ после `*`, `SPAUD` переходит по вычисляемому GOTO
(SPAUD /0137B, /0350B) на 20 ветвей:

| ветвь | символ | адрес SPAUD |
|-------|--------|-------------|
| 1  | `F` | 0375 |
| 2  | `T` | 0434 |
| 3  | `S` | 0441 |
| 4  | `/` | 0555 |
| 5  | `G` | 0611 |
| 6  | `P` | 0652 |
| 7  | `E` (конец текста) | 0677/0673 |
| 8  | `*` перед пробелом/концом карты | 0731 |
| 9  | `C` | 0735 |
| 10 | `H` | 0764 |
| 11 | `D` | 1014 |
| 12 | `N` | 1027 |
| 13 | `O` | 1070 |
| 14 | `W`, `(` | 1227 |
| 15 | `M` | 1267 |
| 16 | `R` | 1756 |
| 17 | завершение `*E` | 2201 |
| 18 | `K` | 2242 |
| 19 | цифра (числовой префикс) | 2333 |
| 20 | выход из SPAUD (возврат в SCHEMA) | 2347 |

Русские буквы, совпадающие по начертанию с латинскими (А В Е К М Н О Р С Т Х),
вводятся теми же кодами: `*Т` = `*T`, `*С` = `*C` и т.д. `Д` ≠ `D`.

Неизвестный символ после `*` (A, B, I, `.`, `*`, …) — ошибка 10.
`*E` в начале карты — конец текста `*RED`; остаток карты читается как следующее
ключевое слово блока (`*EВВ` → ошибка 100).
Число без команды за ним (`*5ЖЖ`) — листинг программ, как `*MF` (см. ниже).

Первая карта блока `*RED` разбирается отдельно (FIRCAR): `*RG`, `*RU`, `*N`, `*nN`
там не проходят через диспетчер SPAUD.  В остальных картах `*RG`/`*RU` — ветвь 16,
`*N` — ветвь 12.  Поэтому пробные вставки начинаются со строки-заполнителя.

### Установленное поведение (умолчания: 2 страницы по 64 позиции на листе
АЦПУ, текст в позициях 6–61, выравнивание по обоим краям)

- Текст без команд — заполнение строк (слова переносятся целиком), выравнивание
  пробелами по ширине.
- `*S` — абзац: новая строка, отступ 3; `*nS` — перед абзацем n−1 пустых строк.
- `*/` — перевод строки; `*n/` — перевод строки и n−1 пустых строк
  (`*0/` = `*1/` = `*/`).
- `*D` — остаток карты берётся как есть (пробелы сохраняются), перевода строки
  нет; типичное употребление `*/*D…` — строка «как есть».
- `*nG` — переход на позицию n строки (относительно левого поля, 1 = первая
  позиция); если текущая позиция уже дальше — ничего.
- `*nC` — следующий символ повторяется n раз (`*10C ` — 10 пробелов,
  `*20C-` — линия).
- `*Kn` — то же, число после буквы (`*K3Ж` = ЖЖЖ); `*K0Ж` — Ж поглощается.
- `*n(…)` / `*nW…)` — группа текста до `)` повторяется n раз (без n — один раз);
  `)` поглощается. Вне такой группы `)` — обычный символ.
- `*nF<c>` — символом c заполняется остаток строки и ещё n−1 строк целиком;
  без числа n=1; `*0F<c>` — c поглощается.
- `*T<текст>` — остаток карты по центру, после него 2 пустые строки (заголовок);
  `*MD<текст>` — остаток карты по центру, без пустых строк.
- `*nP` — n раз «конец страницы» (`*P` — новая страница, `*3P` — две пустые).
- `*nH` — следующие n символов выводятся как есть (без разбора `*`); без числа
  n=1: `*H*` — литерал `*` (в корпусе: `X*H*LN(C)`).
- `* ` (звёздочка перед пробелом/концом карты) — звёздочка опускается.
- Буква Ё в наборе отсутствует и выбрасывается.
- `*RG` — рамка вокруг страницы; в середине текста — SPAUD 1764
  (`REGIM+7`:=0), рамка со следующей страницы.
- Буква Ё на деле превращается в пробел (`ЗВЁЗДОЧКА` → `ЗВ ЗДОЧКА`).
- `*0STA` — формат A: одна широкая страница на листе.
- `*nN` — следующая страница получает номер n (нумерация включается);
  `*NN` — номера страниц не печатаются (`REGIM+4` := 0).
- `*0STO` — возврат к обычному формату (2 страницы на листе).
- `*1STP…`/`*1STG…` — шапка/подвал только на первой странице; `*0ST…` — на всех.
- `*STG<текст>` — строка внизу страницы (подвал).
- `*STN` — сдвигает шапку ниже (смысл не выяснен).
- `*0STP<текст>` — строка обозначения документа под номером страницы.
- `*nMCS a w` — левое поле a, ширина строки w (не правое поле!); действует n
  строк, `*0MCS` — до отмены; `*MCS` пишет `*FORMA*+10/+11`, ошибки 20 (нет
  числа), 30 (за пределами страницы).
- `*nMCP a b` — пишет `*NUST*+7` = n, `*NUST*+5/+6` = a, b (размеры страницы?),
  ошибки 20, 40; ошибка 60, если `*NUST*+1` ≠ 1.  В SCHEMA умолчания
  `*0MCP112 48`, `*0MCP68 66`, `*0MCP1 02 41`.
- `*nRL` — межстрочный интервал: n пустых строк между строками (`REGIM+1` := n+1);
  без числа — n=1, `*0RL` — обычный.
- `*nRC` — разрядка: между буквами n пробелов (`REGIM+2` := n+1); без числа n=1,
  `*0RC` — отмена.  Употребляется `*RC ОС *0RC`.
- `*nRF<c>` — заполнить символом c до позиции n (оглавление: `*56RF.  5`);
  позиция за правым полем — ошибка 80.
- `*RT` — `REGIM+11` := 1 (по умолчанию): перенос по словам с выравниванием;
  `*OLR` — `REGIM+11` := 0: строки заполняются посимвольно, слова рвутся.
- `*RU` — широкий формат: одна страница ~120 позиций на листе; `*1RU` — сначала
  дописать текущий лист; `*ORU` — возврат к обычному формату.
- `*n M=текст$` — определение макро n (тело может занимать несколько карт,
  до `$`); `*nM` — вставка (раскрывается в месте вызова, вложенные вызовы
  раскрываются).  `*M=` ≡ `*1M=`.  Номера только подряд 1, 2, …; повторное
  определение или 0 — ошибка 91.  Хранилище `*MKR*` (500 слов).
- `*MF` — ветвь 20 (2347): листинг программ.  Последующие карты печатаются как
  есть (позиция c → c+3), после карты с `END` 2 пустые строки, карта `///`
  завершает режим.  Без `///` весь ввод уходит в листинг и выдачи нет — так
  выглядели первые опыты («ввод теряется»).
- Число без команды за ним (`*5ЖЖ`) — тоже ветвь 20, тот же листинг.
- `*ST a1 b1 a2 b2 …` — колонки без линеек: колонка k — позиции ak..bk
  (относительно левого поля); число позиций нечётно — ошибка 62.  Карта
  `*ST…` должна содержать только числа (иное — ошибка 61).  Следующая карта
  обязана начинаться с ` k)` (иначе ошибка 66).  ` k)текст` — ячейка колонки k,
  карты без ` k)` продолжают текущую ячейку; текст в ячейке заполняется и
  выравнивается по ширине колонки; возврат к меньшему номеру колонки — новая
  строка таблицы; `$` — конец таблицы.  Пример — титульный лист dispak-descr.txt.
  В первой карте блока `*ST…` разбирается FIRCAR как заголовок — не ставить.
- `*SL p1 p2 … pk` — таблица с линейками: вертикальные линии в позициях p1…pk
  (k−1 колонок), горизонтальные линии над, между и под строками; синтаксис
  ячеек тот же.  Внутри ячейки `*NL`, `*NR`, `*NU`, `*ND` убирают у этой
  ячейки левую, правую, верхнюю, нижнюю линию (COMANN, `*LRE*`).
- `*N<буква>` с иной буквой — `N` поглощается, буква остаётся текстом.
- `*NN` (в первой карте) — номер страницы не печатается.

### Ошибки (KLAIDA: «ERROR NR. n» + образ перфокарты, останов)

| N | где |
|---|-----|
| 10 | SPAUD (13 мест) — недопустимая команда |
| 20 | CHAPAG, SPAUD |
| 30 | BEGSTR, SPAUD |
| 40 | CHAPAG, SPAUD |
| 50 | SCAN |
| 60 | SPAUD |
| 61 | `*SL…`, `*ST` (через переменную) |
| 62 | SPAUD (`*ST10 20 30`) |
| 65 | ENDPG, SEKLYG |
| 68 | RASTXT |
| 80 | SPAUD |
| 100 | SCHEMA — неизвестный блок |
| 101 | BEGPUS, ENDKOR |

Карта длиннее 80 символов — ОС: «БЫЛИ ОШИБКИ ПРИ ТРАНСЛЯЦИИ ИЛИ В НАБИВКЕ».

## Порождающие режимы (оверлеи, загружаются LOADGO)

Все они формируют текст в разметке `*RED` (через WRIKOR/ENDKOR в буфер) и
печатают его средствами SPAUD.  Блок такого режима завершается картой `$`
(не `*E`); после `$` — следующее ключевое слово блока.  Параметр на карте
режима пишется после 6-й позиции (ключевое слово сравнивается как 6 литер:
`*IPO  1`).

- `*NOT` (NOTFOR, WHATYP, TARNYB, APNOTF): структурный псевдокод.  WHATYP
  распознаёт первые слова карт по строке `DOWHILEIFCASEPERFORMBEGINTHENELSEEND`
  (DO, WHILE, IF, CASE, PERFORM, BEGIN, THEN, ELSE, END) и `$`.  Вывод — страница
  в рамке, BEGIN — заголовок по центру, тела IF/THEN/ELSE, DO WHILE сдвигаются на
  4 позиции.  Пример: tests/siprod/cases (см. not1).
- `*SUB` (PAPAPR → RMAKR(18), RMAKR(19), PAPRAP): паспорт подпрограммы.  Поля
  `0=имя`, `1=`…`10=` (разделы 1. ЯЗЫК ПРОГРАММИРОВАНИЯ — 10. ССЫЛКИ), конец `$$`.
  RMAKR заранее определяет макро (заголовки разделов, таблица параметров
  `1)ИМЯ 2)ТИП 3)ВХОД 4)ВЫХОД 5)НАЗНАЧЕНИЕ` по `*ST 1 6 8 10 …`).  Раздел 6
  (параметры) в опыте пуст — формат ввода не выяснен.
- `*IPO` (WRIIPO, IPONUM, RASKOM): диаграмма HIPO на широкой странице в рамке:
  колонки INPUT / PROCESS / OUTPUT, метка `IPO n` (n — число на карте `*IPO`),
  строки `1)…`, `2)…`, `3)…` — в колонки; конец `$`.
- `*HCH  n k` (WRITEH: ONEPLA, WRILIN, WRIHOR, WRIVER, TWOPLA): иерархическая
  схема — узел n (текст на следующей карте) и k подчинённых n.1…n.k (по карте
  на каждый), без `$`.  k=1 — деление на нуль, k≥6 — ошибка 68, без чисел —
  ошибка 102; текст вместо второго числа — «КОНТРОЛЬ КОМАНДЫ» (SYTINT уходит
  на 0).  Ранняя запись «не работает» была ошибкой: требуется два числа.
- `*REP` — есть в таблице SCHEMA (седьмой), но на верхнем уровне даёт
  ошибку 100; назначение не выяснено.
- `*END` — конец входного потока.  Несколько блоков `*RED` подряд продолжают
  один документ (даже ту же строку).

## Разбор неясностей (2026-10-20)

- `*REP n` — не блок, а оператор верхнего уровня (SCHEMA: BLO=7 → 0147, число
  через SYTINT в `*RPT*`; ENDPG печатает каждый лист n раз).  Таблица SCHEMA
  содержит и 8-й элемент `*STA`.  Регистр 7 в SCHEMA указывает на пул констант
  `*0661B` (0,1,3,4,5,6,7,8,…), так что `7,X-A,7` — сравнение с 8.
- `*nSTA` — формат A на n страниц (счётчик `*STAND*+1` в ENDPG), `*0STA` —
  навсегда.  `*nSTN` — отмена шапки (1) или подвала (2).  Прежняя запись «STN
  сдвигает шапку» — ошибка: шапка ниже на последней странице и без STN.
- `*nMCP w h` — страница w×h по центру места на листе, n страниц (0 — навсегда);
  в обычном формате w ≤ 64 (иначе ошибка 40).  Ошибка 60 — `*MCP`/`*ST`/`*SL`
  в ячейке таблицы (`*NUST*+1`=2 ставит RASTXT).
- `*RU` на первой карте работает полностью; «только первая строка» была
  последней невыровненной строкой абзаца.
- `*nN` требует после `N` пробела/конца карты.
- `*SUB`, раздел 6: карты `=имя т в в назначение` дают таблицу параметров
  (PAPRAP 0472: первый символ сравнивается с `=` из `*0751B`).
- `*IPO`: тело — таблица `*ST` из трёх колонок; карты до первой `k)` — под
  OUTPUT.  `*HCH`: многоуровневая схема — блок на узел, номер до 4 уровней.
- Ошибка 65 — слишком высокая строка таблицы; 101 — более ~100 карт,
  сформированных одним блоком порождающего режима (`*NOT` ~92 строки).
- Инструменты: `tests/siprod/pages.py` (раскладка страниц по листам),
  `tests/siprod/frames.py` (рамки).
