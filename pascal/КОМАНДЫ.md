# Команды режима `*RED` — справочник

Реализация редактора СИПРОД-П (`redakt.pas`). Синтаксис: `*` + число +
команда; число обычно задаёт «количество» (повтор, интервал) и по
умолчанию равно 1 (`*0` часто означает «отмену»). Текст поля
обычного формата — позиции 6–61 строки АЦПУ-128; лист несёт две
страницы по 64 позиции (нечётная слева, чётная справа), листы
разделяются `- n -` номерами страниц.

## Строки и абзацы

| команда | действие |
|---|---|
| текст без команды | заполнение строки словами с выравниванием по обоим краям; абзацный отступ 3 после `*S` |
| `*nS` | абзац: новая строка с отступом; `n−1` пустых строк перед ним |
| `*n/` | перевод строки; `n−1` пустых строк (`*0/` = `*/`) |
| `*D` | остаток карты — как есть, пробелы сохраняются, перевода строки нет (`*/*D…` — строка рисунка) |
| `*nG` | переход на позицию `n` строки (от левого поля), если текущая позиция левее |
| `*nC<c>` | повторить литеру `<c>` `n` раз (`*20C-` — линия) |
| `*Knc` | то же, число после буквы: `*K3Ж` = `ЖЖЖ`, `*K0Ж` — `Ж` поглощается |
| `*n(текст)` / `*nWтекст)` | группа до `)` повторяется `n` раз (без числа — 1); вне группы `)` — обычная литера |
| `*nF<c>` | заполнить остаток строки и ещё `n−1` строк литерой `<c>` |
| `*nH` | следующие `n` литер — как есть, без разбора `*` (`*H*` — литера `*`) |
| `*Tтекст` | остаток карты по центру, после — 2 пустые строки (заголовок) |
| `*MDтекст` | остаток карты по центру без пустых строк |
| `*E` | конец текста блока `*RED` (остаток карты — следующее ключевое слово) |
| число без команды | `*5ЖЖ` — листинг программ, как `*MF` |

## Позиционирование и форматы

| команда | действие |
|---|---|
| `*nP` | `n` раз «конец страницы» (`*P` — новая страница, `*3P` — две пустые) |
| `*nN` | следующая страница получает номер `n`; в первой карте блока пробел после `N` не обязателен (`*254N*1RL`), дальше — обязателен (`*7N `) |
| `*NN` | номера страниц не печатаются |
| `*nMCS a w` | левое поле `a` (текст с позиции 5+`a`), ширина строки `w`; действует `n` строк, `*0MCS` — до отмены; умолчание `*0MCS1 56` |
| `*nMCP a b` | размещение страниц на листе (числа проверяются на ≤127) |
| `*nRL` | интервал `n`: `n−1` пустых строк между строками текста (`*1RL` — через строку) |
| `*nRC` | разрядка `n`: после каждой литеры слова `n` пробелов, `*0RC` — отмена (`*RC РАЗРЯДКА *0RC`) |
| `*OLR` / `*RT` | блок «как есть» между ними: строки без заполнения, без выравнивания |
| `*RU` / `*ORU` | широкий формат (страница во всю ширину листа) / возврат; `*1RU` — допечатать текущий лист |
| `*RG` | рамка вокруг страниц; заданная в середине текста — со следующей страницы |

## Штамп и колонтитулы (ЕСПД)

| команда | действие |
|---|---|
| `*nSTA` | формат А: одна страница 84 позиции на листе |
| `*nSTO` | возврат к обычному формату (2 страницы по 64) |
| `*nSTPтекст` | штамп — строка под номером страницы; `*0STP` — на каждой странице, `*1STP` — только на первой |
| `*nSTGтекст` | подвал — строка внизу страницы; `*0STG` — на каждой, `*1STG` — только на первой |
| `*STN` | сдвиг штампа ниже (принимается без действия) |

Смена формата в середине текста действует со следующей страницы;
первая карта блока `*RED` разбирается особо (FIRCAR): в ней `*RG`,
`*RU`, `*nN`, `*NN`, `*nST…` действуют немедленно.

Нумерация страниц сквозная по всем блокам задания: после напечатанного
листа очередной лист получает следующий номер; повторно используется
только номер, еще не попавший на бумагу (`*P` перед сменой формата).

## Таблицы

| команда | действие |
|---|---|
| `*ST a1 b1 a2 b2 …` | колонки без линеек: колонка `k` — позиции `ak..bk` |
| `*SL …` | то же с линейками `I` |
| `k)текст` | карта-ячейка: текст в колонку `k`; маркер распознается и в середине
карты - текст до него идет в текущую ячейку (титульный лист: ` 1)РУКОВОДИТЕЛЬ РАБОТЫ 2)ИСПОЛНИТЕЛЬ`) |
| текст без `k)` | продолжение текущей ячейки |
| `*NL *NR *NU *ND` | убрать левую/правую/верхнюю/нижнюю линейку ячейки |
| `$` в первой позиции | конец таблицы (`*TD` — выдача) |

## Макроопределения

| команда | действие |
|---|---|
| `*nM=тело$` | определить макро `n`; тело до `$`, может занимать несколько карт |
| `*nM` | вставить макро `n`; вложенные вызовы раскрываются (до 6 уровней) |

## Листинг программ

| команда | действие |
|---|---|
| `*MF` | режим листинга: карты печатаются как есть, строки 73–80 — нумерация |
| `///` в первых позициях | конец листинга |

## Блок *DRK — схемы ДРАКОН встроенным режимом

Блок верхнего уровня, наравне с `*RED` (в оригинальном СИПРОДе — таблица
диспетчера SCHEMA /0747B, где дракону положен свой режим). Исходник схемы
транслируется и печатается самим редактором, без карт разметки `*/*D`.
Рисуются все 25 икон рис. 4 книги Паронджанова (ключевые слова — в
`DRAKON.md`, п. 1; испытание — схемы 18 и 19 в `pascal/схемы/`):

```
*DRK
ЗАГОЛОВОК: Текст заголовка
ВЕТКА: Имя ветки
    ДЕЙСТВИЕ: ...
    ЕСЛИ: условие?
        ТО
            ...
        ИНАЧЕ
            ...
    АДРЕС: метка перехода
КОНЕЦ
*E
*END
```

| правило | действие |
|---|---|
| вход | `*DRK` — ключ блока; распознаётся только в начале карты, как `*RED` |
| формат | блок сам включает рамку `*RG` и широкий формат `*RU` — как разметка генератора; номер страницы не тратится |
| исходник | карты до `*E` (или конца данных); значимы позиции 1–72; карта с `*` в начале — комментарий |
| `КОНЕЦ` | обычная икона (в силуэте — конец ветки), блок заканчивается только `*E` |
| печать | строка рисунка идёт тем же путём, что карта `*/*D`: рамки на границах страниц, номера и штампы ведёт редактор; выдача побайтно равна печати через разметку (`регресс.sh`, секция «*DRK = разметка») |
| ёмкость | 72 узла, 240 строк рисунка, 6 плеч у узла (у отдельного `drakon.pas` — 120/240/8; урезано ради памяти: редактор+транслятор в одном образе ~32К слов) |
| экономия памяти | строки листа упакованы; ячейки таблиц и рисунок ДРАКОН наложены (овереи в вариантной записи — живут в разное время) |

## Ошибки

Ошибки печатаются в формате оригинала (`ERROR NR. n` + `ОБРАЗ
ПЕРФОКАРТЫ:`): 10 — неизвестная команда; 20 — нет числа; 30, 40 —
число вне диапазона; 61, 62, 64, 66 — таблицы; 80 — нет места на
строке; 91 — макро; 100 — не текст блока `*RED`.
