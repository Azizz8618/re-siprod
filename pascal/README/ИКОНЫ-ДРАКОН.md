# Иконы ДРАКОН И1-И25: рисунок и реализация в пасскальной связке

Полный комплект икон языка ДРАКОН (по рис. 4 книги В.Д. Паронджанова),
как он рисуется редактором СИПРОД-П: встроенным режимом `*DRK`
(`../source/redakt.pas`) и отдельным транслятором (`../source/drakon.pas`)
- формы в обоих исходниках совпадают побайтно, печать разметки `*/*D`
и блока `*DRK` идентична (регресс `../scripts/регресс.sh`, секция
«*DRK = разметка», 22 схемы).

Файл дополняет корневой `../../DRAKON.md` (синтаксис и компоновка) и
`ЕДИНОЕ-ЗАДАНИЕ-DRK.md` (маршрут печати): здесь - только сами иконы,
их рисунок, выходы, размеры и место в коде. Живые рисунки - эталонные
схемы-испытания каталога `../схемы/`: `18-иконы-примитив` (все иконы
примитива), `19-иконы-силуэт` (И1, И7, И9, И8, И2, гребёнка И25),
`20-силуэт-многоветов`, `21-выбор-многоветов`, `22-адаптив-тексты`;
эталоны сняты с печати АЦПУ-128.

## 1. Общие правила рисунка

* **Литеры.** Набор ГОСТ 10859 на бумаге АЦПУ-128 не содержит `\` (код
  175 печатается как `Щ`, на входе карт отвергается) и фигурных скобок
  `{ }`. Поэтому: скос влево-вниз рисуется литерой `/`, скос
  вправо-вниз - `(`; сходящиеся пары (клин, сужение трапеции, щит) -
  скобочной парой `( ... )`, заодно передающей округлую вершину.
  Полуовалы - `.`, `'`, скобки.
* **Адаптивный размер.** Икона подгоняется под подпись: короткая даёт
  узкую икону (поле от 5 знаков), подпись до 30 знаков держится в одну
  строку, длинная переносится по словам на 2-3 строки равных долей.
  Ниже `nwl` - число строк подписи.
* **Чётность поля (с 11.11.2026).** Поле однострочной подписи той же
  чётности, что и подпись: пробелов слева и справа от надписи поровну.
  Поле многострочной подписи нечётное - одна средняя колонка, к ней
  прилегают вершины клиньев и острия (у икон с чётной подписью икона
  стоит на полколонки левее оси - соединения ведёт ось шампура).
* **Высоты.** Высота каждой иконы фиксирована формулой от `nwl`
  (см. сводную таблицу) - на неё опирается разметка страниц и правило
  переноса иконы на новую страницу только целиком.
* **Выходы и валентные точки.** Боковое плечо (выход «нет» вопроса,
  правые ветки вариантов) примыкает к правой стене иконы на середине
  высоты только у вопроса; у остальных икон боковые линии выходят от
  нижней грани (`exrow`). Валентные точки рисуются чертой `--`:
  И11 - слева, И17 - с обеих сторон, И19 - справа.
* **Две реализации.** Формы разбиты на шесть процедур `picon1..picon6`
  (предел числа команд в блоке у компилятора PASCOMPL 15.1): диспетчер
  `makeicon` (`redakt.pas`, строки 3322-3360) берёт вид узла `kindof`
  и передаёт в нужную picon. В `drakon.pas` те же формы (строки
  645-1040), таблица видов - комментарий перед `kindof` (строки
  386-398). Внутренний вид `kind` (0-24) - порядок рис. 4 книги, он
  не совпадает с нумерацией И.

## 3. Каркас схемы: И1, И7, И2, И8

### И1. Заголовок - полуовал

Заголовок алгоритма (примитив) или силуэта; единственная икона над
ветками. В силуэте от заголовка расходится верхняя шина гребёнки.

```
.-------------.
(ЗАГОЛОВОК И1)
'-------------'
```

### И7. Имя ветки - щит

Начало смысловой части силуэта. Стены ниже подписи сходятся скобками
к нижней вершине (две убывающие пары `( ... )` с усечённой вершиной
`(_____)`) - нижней грани нет, ветка «заострена» вниз. Верхняя шина
подводится к верхней грани щита.

```
+----------+
|ПОДГОТОВКА|
 (        )
  (______)
```

### И2. Конец - малый полуовал

Конец алгоритма (последняя ветка силуэта) или маршрута. Без подписи
печатает слово `КОНЕЦ` (`makeicon`: пустая подпись заменяется пятью
литерами). Выход из ветки с И2 уходит вниз, на нижнюю шину не
возвращается.

```
.-----.
(КОНЕЦ)
'-----'
```

### И8. Адрес - домик

Переход к началу другой ветки силуэта: ветка кончается И8, линия
идёт вниз к нижней шине и возвращается в заголовок. Крыша - с
11.11.2026 симметричная скобочная пара `( )` / `(   )` по обе стороны
оси шампура (у оригинала `/( ` со сдвигом вершины на полколонки);
ниже - прямоугольник с подписью.

```
  ( )
 (   )
+-----+
|АДРЕС|
+-----+
```

## 4. Прямоугольные иконы: И3, И9, И10, И11

### И3. Действие - прямоугольник

Обычная операция. Простейшая икона: рамка `+ | +`, подпись внутри.

```
+-----------+
|ДЕЙСТВИЕ И3|
+-----------+
```

### И9. Вставка - двойные стенки

Ссылка на вставку (подпрограмму): двойные боковые стенки
`|| текст ||` отличают её от действия И3.

```
+------------+
||ВСТАВКА И9||
+------------+
```

### И10. Полка

Полка синхронизатора: подпись занимает верхнюю половину, нижняя -
пустой отсек, отделённый горизонтальной гранью.

```
+---------+
|ПОЛКА И10|
+---------+
|         |
+---------+
```

### И11. Формальные параметры

Параметры (в примитиве ставится под заголовком). Прямоугольник, у
которого валентная точка `--` слева на середине высоты - место входа
линии фактических параметров.

```
  +------------------------+
--|ФОРМАЛЬНЫЕ ПАРАМЕТРЫ И11|
  +------------------------+
```

## 5. Развилки: И4, И5, И6

### И4. Вопрос - шестиугольник

Развилка `ЕСЛИ` и заголовок цикла-пока `ЦИКЛ`. Пять поясов: короткая
верхняя грань, скобочные плечи `(`, `)`, строка подписи со стенами
`|`, снова скобочные плечи, короткая нижняя грань. Выход «да» -
вниз (маршрут `ТО`), выход «нет» - вправо от правой стены на середине
высоты (маршрут `ИНАЧЕ`); с 11.11.2026 оба верхних плеча рисуются
`(` и `)` (нижние и у оригинала были парой).

```
  +-------+
 (         )
| ВОПРОС И4 |
 (         )
  +-------+
```

Цикл `ЦИКЛ`: та же икона, тело справа, петля возврата - по внешнему
краю (см. И24).

### И5. Выбор - параллелограмм

Переключатель `ВЫБОР`; под ним - блоки `ВАРИАНТ`, каждый вариантом
И6 со своей вертикалью. Единственная икона, сохранившая слэши
(11.11.2026): наклон стен - сам наклон параллелограмма, верх сдвинут
вправо на число строк подписи.

```
  +--------+
 /ВЫБОР И5/
+--------+
```

### И6. Вариант - прямоугольник с клином

Значение переключателя: прямоугольник с подписью варианта, ниже -
клин, вершина которого усечена чертой `(_____)`; клин остриём указывает
на вертикаль своего варианта.

```
+-------------------+
|ВАРИАНТ С КЛИНОМ И6|
+-------------------+
 (                 )
  (_______________)
```

## 6. Циклы: И12, И13, И24, И25

### И12. Начало цикла ДЛЯ

Заголовок арифметического цикла. Три пояса: короткая верхняя грань,
первая строка подписи со скобочными стенами `( ... )`, нижняя грань
полной ширины. С 11.11.2026 стены первой строки - `(` и `)` (левая у
оригинала была `/`), верх стал зеркалом низа И13.

```
 +------+
(ЦИКЛ ДЛЯ)
+--------+
```

### И13. Конец цикла ДЛЯ

Закрывает тело цикла: верхняя грань полная, последняя строка подписи
со скобочными стенами, короткая нижняя грань. От правой стены на
середине высоты транслятор выводит петлю возврата И24.

```
+---------+
(КОНЕЦ ДЛЯ)
 +-------+
```

### И24. Петля цикла

Возврат от И13 к вертикали между И12 и телом цикла. Рисуется
автоматически (`drakon.pas`: от правой стены КДЛ на середине высоты -
вправо, вверх и остриём `<` в вертикаль); ключевое слово `ПЕТЛЯ`
задаёт линейную икону явно.

```
|<------+
|       |
```

### И25. Петля силуэта (гребёнка)

Возврат веток силуэта в заголовок: остриё `<` в вертикаль заголовка,
горизонталь к правому краю, ниже - зубцы-вертикали по числу веток.
Рисуется автоматически (нижняя шина силуэта); ключевое слово
`ГРЕБЕНКА` задаёт линейную икону явно.

```
|<-------------
|   |   |   | |
```

## 7. Ввод-вывод: И14, И15

### И14. Вывод - полая стрелка наружу

Прямоугольник, справа за стеной полая стрелка `===>` (полая - из
литер `=`): выдача наружу.

```
+---------+
|ВЫВОД И14|===>
+---------+
```

### И15. Ввод - стрелка внутрь

Прямоугольник, справа остриё `<` и черта `<===`: приём снаружи
внутрь иконы.

```
+--------+
|ВВОД И15|<===
+--------+
```

## 8. Время и параллелизм: И16-И20

### И16. Пауза - трапеция

Задержка. Прямоугольная верхняя часть, ниже сужение скобочной парой
и короткая нижняя грань - трапеция, сужающаяся вниз.

```
+---------+
|ПАУЗА И16|
 (       )
  +-----+
```

### И17. Период

Та же трапеция с валентными точками `--` с обеих сторон на середине
высоты: период соединяется и слева, и справа.

```
  +----------+
  |ПЕРИОД И17|
-- (        ) --
    +------+
```

### И18. Пуск таймера

Трапеция с двойными стенками `|| текст ||` и двойным сужением
`(( ... ))`.

```
+------------------+
||ПУСК ТАЙМЕРА И18||
 ((              ))
   +------------+
```

### И19. Синхронизатор

Трапеция с одной валентной точкой `--` справа: ожидание по таймеру.

```
  +-----------------+
  |СИНХРОНИЗАТОР И19|
   (               ) --
    +-------------+
```

### И20. Параллельный процесс

Основной прямоугольник с подписью и второй контур, сдвинутый
вверх-вправо; от правой стены основного - черта-соединение к его
вертикали.

```
                                +--+
     +------------------------+    |
     |ПАРАЛЛЕЛЬНЫЙ ПРОЦЕСС И20|----+
     +------------------------+
```

## 9. Комментарии: И21, И22, И23

### И21. Комментарий - двойная рамка с полуовалом

Пояснение на шампуре: внешний прямоугольник, внутри - полуовал с
текстом (стены `(` `)`, верх/низ `.` `'`).

```
+-----------------+
|.---------------.|
|(КОММЕНТАРИЙ И21)|
|'---------------'|
+-----------------+
```

### И22. Правый комментарий

Пояснение, ставящееся правее икон: колонка скобок `(` слева от текста
(фигурных скобок `{ }` в ГОСТ 10859 нет). Рамки нет, высота - числу
строк подписи.

```
( ТЕКСТ ПРАВОГО КОММЕНТАРИЯ
```

### И23. Левый комментарий

Пояснение левее икон: текст, колонка скобок `)` справа от него.

```
ТЕКСТ ЛЕВОГО КОММЕНТАРИЯ )
```

## 10. Отступление рисунка от оригинала (11.11.2026)

Рисунок икон в пасскальной связке сознательно отходит от оригинала
(см. `ЕДИНОЕ-ЗАДАНИЕ-DRK.md` и журнал `README.md`):

1. И4 (вопрос): верхние плечи `(` и `)` - у оригинала `/` и `(`;
2. И12 (начало цикла ДЛЯ): стены первой строки `(` и `)` - у
   оригинала `/` и `(`;
3. И8 (адрес): крыша - симметричная пара `( )` / `(   )` по обе
   стороны оси - у оригинала `/( ` со сдвигом вершины на полколонки;
4. поле однострочной подписи одной чётности с подписью - пробелов
   слева и справа поровну (у оригинала поле всегда нечётное, лишний
   пробел уходил влево);
5. икона переносится на новую страницу только целиком (у оригинала
   рвётся построчно);
6. И5 (выбор) сохраняет слэши - это наклон параллелограмма, а не скос.

Причина отбора - правило литер ГОСТ 10859 (раздел 1) и равные поля
подписей; из-за отступления сверка строк рисунков с оригиналом верна
для текста, но не для рисунков схем, согласие разметки `*/*D` и
`*DRK` сохраняется побайтно. Рисунок эталонного генератора
(`../../tools/drakon_markup.py`, модуль `drakon/drakon.madlen`)
остаётся по оригиналу и описан в `../../DRAKON.md`, раздел 3.
