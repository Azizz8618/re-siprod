# Подробные блок-схемы работы редактора *RED (язык ДРАКОН)

Одиннадцать схем (07-17) дополняют каталог `../../drakon/schemes`
(01-06, модули оригинального СИПРОДа): здесь работа редактора разобрана
подробно, по логике реализации связки - `../redakt.pas` и
`../drakon.pas`, - с отсылками к командам и ошибкам режима `*RED`
(`../КОМАНДЫ.md`, `../../SIPROD.md`).

## Состав

| файл | что на схеме | в redakt.pas |

| `08-сканер-карты.drakon` | просмотр карты, звёздочка и команда, граница карты и закрытие слова | scancard |

## Файлы

* `<имя>.drakon` — исходник схемы (правила: `../../DRAKON.md`);
* `<имя>.txt` — рисунок схемы: эталонный генератор
  `../../tools/drakon_markup.py`;
* `печать-каталог.txt` — все одиннадцать схем, напечатанные на АЦПУ
  связкой: `drakon.pas` (разметка) -> `redakt.pas` (печать, том 2348,
  зона 2150(8), эмулятор dispak).

## Сверка и печать

Рисунки транслятора сверялись с эталонными на всех схемах:

```
sed 's/[ёЁ]/Е/g' 07-главный-цикл.drakon > /tmp/s.dat
./../прогнать-с-тома.sh drakon /tmp/s.dat > /tmp/s.out
python3 ../сверить-дракон.py /tmp/s.out 07-главный-цикл.txt   # СОВПАДАЕТ
```

Каталог печатается так (та же цепочка, что и отдельная схема из
`../README.md`):

```
for f in схемы/*.drakon; do
    sed 's/[ёЁ]/Е/g' "$f" > /tmp/s.dat
    ./прогнать-с-тома.sh drakon /tmp/s.dat >> /tmp/каталог.txt
done
echo '*END' >> /tmp/каталог.txt
./прогнать-с-тома.sh redakt /tmp/каталог.txt > схемы/печать-каталог.txt
```

Ширина каждого рисунка - не более 71 позиции при лимите печатной зоны
127, знак вопроса на АЦПУ печатается градусом (в наборе ГОСТ-10859
вопросительного знака нет; так же ведут себя схемы 01-06).
