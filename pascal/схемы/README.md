# Подробные блок-схемы работы редактора *RED (язык ДРАКОН)

Шестнадцать схем (07-22) дополняют каталог `../../drakon/schemes`
(01-06, модули оригинального СИПРОДа): здесь работа редактора разобрана
подробно, по логике реализации связки - `../redakt.pas` и
`../drakon.pas`, - с отсылками к командам и ошибкам режима `*RED`
(`../КОМАНДЫ.md`, `../../SIPROD.md`).  Схемы 18-22 - испытания
транслятора: полный комплект икон И1-И24 по рис. 4 книги Паронджанова
(18), силуэт в колонки с автоматической гребёнкой (19), силуэт с
пятью ветками, циклом и развилкой (20), выбор с четырьмя вариантами
(21), адаптивный размер икон (22).

## Файлы

* `<имя>.drakon` — исходник схемы (правила: `../../DRAKON.md`);
* `<имя>.txt` — рисунок схемы (эталон перегенерируется прогоном
  `drakon.pas` на БЭСМ-6: `перегенерировать-эталоны.sh`);
* `печать-каталог.txt` — все шестнадцать схем, напечатанные на АЦПУ
  связкой: `drakon.pas` (разметка) -> `redakt.pas` (печать, том 2348,
  зона 2150(8), эмулятор dispak); сборка - `../печать-каталога.sh`.

## Сверка и печать

Рисунки транслятора сверялись с эталонными на всех схемах:

```
sed 's/[ёЁ]/Е/g' 07-главный-цикл.drakon > /tmp/s.dat
./../прогнать-с-тома.sh drakon /tmp/s.dat > /tmp/s.out
python3 ../сверить-дракон.py /tmp/s.out 07-главный-цикл.txt   # СОВПАДАЕТ
```

Каталог печатается так (та же цепочка, что и отдельная схема из
`../README.md`; тот же каталог печатается и одним модулем без карт
разметки - исходники блоком `*DRK`, выдача та же):

```
sh ../печать-каталога.sh
```

Эталоны рисунков перегенерируются тем же транслятором:

```
sh ../перегенерировать-эталоны.sh          # все схемы
sh ../перегенерировать-эталоны.sh 19-иконы-силуэт   # одна
```

Ширина рисунка - не более 127 позиций (печатная зона АЦПУ-128;
самый широкий - схема 20, 122 позиции); знак вопроса на АЦПУ
печатается градусом (в наборе ГОСТ-10859 вопросительного знака нет;
так же ведут себя схемы 01-06).  Строка исходника - не более 80
знаков на карте, значимых - не более 72 (столько читает
транслятор), поэтому текст иконы - до ~60 литер.
