# Редактор языка ДРАКОН (модуль БЕМШ)

Редактор схем ДРАКОН — модуль личной библиотеки (PERSO, том 2248) рядом с
библиотекой СИПРОДа.  Модуль читает входной поток (текст программы на ДРАКОН) и
строит разметку СИПРОДа `*RED` для печати схемы на АЦПУ.

## Файлы

| файл | что это |
|---|---|
| `drakon.be` | текст модуля в формате `text/*.be` (собирает `tools/siprod_asm.py`) |
| `src/drakon.be` | тот же модуль в исходном формате МАКРО-БЕМШ (собирает транслятор `БТМАЛФ`, `asmjob.py`) |
| `mklib.py` | сборка библиотеки: каталог + модули СИПРОДа + модуль редактора, запись в рабочую копию тома 2248 |
| `asmjob.py`, `build.py` | сборка модуля штатным транслятором МАКРО-БЕМШ (проверка) |
| `example.drakon` | пример входного потока |

## Сборка и запуск

```
tests/drakon/run.sh                       # собрать библиотеку и запустить
python3 drakon/mklib.py --inp drakon/example.drakon
```

Задание запускает монитор МС «Дубна» с точкой входа `DRAKON`; библиотека
пишется в **рабочую копию** тома 2248 (`drakon/out/2248`), оригинальный образ
`/usr/local/share/besm6/2248` и `siprod.bin` не изменяются.

## Требования к образу модуля (выяснено опытом)

* каталог: новая запись — имя + запись (длина загрузки в словах × 8 в битах
  12..23, дата в битах 24..47); запись вставляется на место завершателя
  каталога, завершатель (пустое имя + `0о7777777777777777`) сдвигается за ней;
* модули размещаются подряд, выровненные по 32 слова; каталог занимает
  первые пять зон образа;
* образ объекта: заголовок (3 слова) + разделы `cmd | const | data | set |
  head | sym | long | debug`; длина `cmd` и `head` — в заголовке.

## Состояние

Работает: сборка модуля, сборка библиотеки, загрузка монитором, чтение
входного потока через `GETSTR` и корректный возврат в монитор.

Тонкости соглашения вызова (проверены опытом):

* выход из главной программы — как у `SCHEMA`: `УИИ М12(М16)` **до**
  `УИА <метка>(М16)`, иначе адрес возврата монитору затирается;
* вызов `GETSTR` затирает М16, поэтому при входе М16 сохраняется в магазин
  (`СЧИМ М16`), а перед выходом восстанавливается (`УИМ М16`).

Далее — разбор текста ДРАКОН, компоновка схемы и вывод разметки `*RED`.
