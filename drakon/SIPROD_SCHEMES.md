# Блок-схемы программы СИПРОД

Документ содержит блок-схемы основных модулей системы СИПРОД, нарисованные на языке ДРАКОН.

## 1. Главный модуль SCHEMA

Схема главного модуля СИПРОДа, который координирует обработку входного потока:

```
ЗАГОЛОВОК: СХЕМА - ГЛАВНЫЙ МОДУЛЬ СИПРОДА
ВЕТКА: Начало
    ДЕЙСТВИЕ: Читать входной поток
    ДЕЙСТВИЕ: Вызвать монитор YESMEMORY

ВЕТКА: Главный цикл
    ЕСЛИ: есть входные данные
    ТО
        ДЕЙСТВИЕ: Определить тип блока
        ДЕЙСТВИЕ: Обработать блок

ВЕТКА: Завершение
    ДЕЙСТВИЕ: Вернуть управление монитору
    КОНЕЦ
```

## 2. Модуль SPAUD (печать)

Модуль печати текста на АЦПУ:

```
ЗАГОЛОВОК: SPAUD - ПЕЧАТЬ ТЕКСТА
ВЕТКА: Инициализация
    ДЕЙСТВИЕ: Установить режимы набора
    ДЕЙСТВИЕ: Определить формат страницы

ВЕТКА: Обработка команд
    ЦИКЛ: пока есть команды
        ВЫБОР: команда
            ВАРИАНТ: *S
                ДЕЙСТВИЕ: Новый абзац
            ВАРИАНТ: *P
                ДЕЙСТВИЕ: Конец страницы
            ВАРИАНТ: *D
                ДЕЙСТВИЕ: Вывести текст как есть
            ВАРИАНТ: *T
                ДЕЙСТВИЕ: Вывести по центру
            ВАРИАНТ: *RG
                ДЕЙСТВИЕ: Установить рамку

ВЕТКА: Завершение
    ДЕЙСТВИЕ: Вывод на АЦПУ
    КОНЕЦ
```

## 3. Модуль GETSTR (чтение строки)

Чтение строки из входного потока:

```
ЗАГОЛОВОК: GETSTR - ЧТЕНИЕ СТРОКИ
ВЕТКА: Начало
    ДЕЙСТВИЕ: Проверить признак NUSTA

ВЕТКА: Читать строку
    ЕСЛИ: это первая строка
    ТО
        ДЕЙСТВИЕ: Инициализировать буфер
    ЕСЛИ: есть данные на ленте
    ТО
        ДЕЙСТВИЕ: Читать слово
        ДЕЙСТВИЕ: Добавить в буфер
    ИНАЧЕ
        ДЕЙСТВИЕ: Установить признак RUSIS

ВЕТКА: Возврат
    КОНЕЦ
```

## 4. Модуль REDTXT (обработка *RED)

Обработка блока редактирования текста:

```
ЗАГОЛОВОК: REDTXT - ОБРАБОТКА БЛОКА *RED
ВЕТКА: Начало
    ДЕЙСТВИЕ: Пропустить заголовок *RED
    ДЕЙСТВИЕ: Установить режим RED

ВЕТКА: Основной цикл
    ЦИКЛ: пока не *E
        ДЕЙСТВИЕ: Вызвать GETSTR
        ВЫБОР: первый символ
            ВАРИАНТ: *
                ДЕЙСТВИЕ: Обработать управляющую команду
            ВАРИАНТ: (пробел)
                ДЕЙСТВИЕ: Обработать текстовую строку

ВЕТКА: Завершение
    ДЕЙСТВИЕ: Вызвать SPAUD
    КОНЕЦ
```

## Генерация схем

Для генерации схем используется эталонный генератор:

```bash
python3 tools/drakon_markup.py drakon/schema.drakon > вывод.txt
```

Для печати через СИПРОД:

```bash
python3 tools/drakon_markup.py drakon/schema.drakon | tests/siprod/run.sh -
```

## Файлы схем

- `schema.drakon` - главный модуль SCHEMA
- `spaud.drakon` - модуль печати
- `getstr.drakon` - чтение строки
- `redtxt.drakon` - обработка *RED
