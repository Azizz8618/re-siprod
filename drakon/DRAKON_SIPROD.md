# Транслятор схем ДРАКОН в СИПРОДе

Документ описывает реализацию и работу модуля-редактора схем языка ДРАКОН в системе СИПРОД.

## 1. Общая схема работы

```
+----------------+     +------------------+     +---------------+
|  Текст на      |     |  Модуль DRAKON   |     |   СИПРОД      |
|  языке ДРАКОН  | --> |  (транслятор)    | --> |   *RED        |
|  *.drakon      |     |  drakon.madlen   |     |   разметка    |
+----------------+     +------------------+     +---------------+
                                                     |
                                                     v
                                              +--------------+
                                              |   АЦПУ       |
                                              |   (печать)   |
                                              +--------------+
```

## 2. Входной язык ДРАКОН

Исходный текст схемы — набор строк с ключевым словом и подписью:

```
ЗАГОЛОВОК: Заголовок схемы

ВЕТКА: Имя ветки
    ДЕЙСТВИЕ: Операция 1
    ДЕЙСТВИЕ: Операция 2

ВЕТКА: Другая ветка
    ЕСЛИ: условие
        ТО
            ДЕЙСТВИЕ: Да
        ИНАЧЕ
            ДЕЙСТВИЕ: Нет

КОНЕЦ
```

### Ключевые слова и иконы

| Ключевое слово | Икона ДРАКОН | Вид рамки |
|----------------|--------------|-----------|
| `ЗАГОЛОВОК` | Заголовок | Скруглённая |
| `ВЕТКА` | Имя ветки | Трапеция |
| `ДЕЙСТВИЕ` | Действие | Прямоугольник |
| `КОММЕНТАРИЙ` | Комментарий | Прямоугольник |
| `ЕСЛИ` | Вопрос | Шестиугольник |
| `ЦИКЛ` | Вопрос | Шестиугольник |
| `ВЫБОР` | Выбор | Трапеция |
| `ВАРИАНТ` | Вариант | Прямоугольник |
| `АДРЕС` | Адрес | Трапеция |
| `КОНЕЦ` | Конец | Скруглённая |

## 3. Виды икон (формы рамок)

```
ПРЯМОУГОЛЬНИК (вид 0):
+--------------------+
|       текст        |
+--------------------+

СКРУГЛЁННАЯ (вид 1):
.--------------------.
(        текст        )
+--------------------+

ТРАПЕЦИЯ (вид 2):
  +--------------------+
 /         текст        /
+----------------------+

ШЕСТИУГОЛЬНИК (вид 3):
  +------------------+
 <       текст       >
 /                  /
  +----------------+
```

## 4. Модуль DRAKON

### 4.1. Исходный код

- **Файл:** `drakon/drakon.madlen` (477 строк)
- **Язык:** Автокод МАДЛЕН (Монитор-80, том 2348)
- **Внешние модули:** GETSTR, WRIKOR, ENDKOR
- **Внешние области:** INS (входной поток, 27 слов)

### 4.2. Алгоритм работы

```
1. HEADER: Вывод заголовка блока *RED/*RG*RU
2. LOOP:
   a. GETSTR: Чтение строки из входного потока
   b. DETECT: Определение вида иконы по ключевому слову
              (также определяет признаки ВЕТКА/ВЫБОР -> смещение)
   c. CONNECT: Рисование соединительных линий
      - вертикальные между иконами одной ветки
      - горизонтальные после развилок (ЕСЛИ/ЦИКЛ)
   d. ICON: Рисование иконы (рамка + текст)
   e. Повтор LOOP пока не кончится поток
3. TRAIL: Вывод завершения *E/*END
```

### 4.3. Структура данных

```madlen
C Переменные модуля:
IKIND    - вид текущей иконы (0-3)
LASTKIND - вид предыдущей иконы
IBRANCH  - счётчик ветвей (для смещения)
BRANCHFL - флаг развития (для горизонтальной линии)
IDEPTH   - уровень вложенности
```

### 4.4. Распознавание ключевых слов

Первые 6 знаков строки сравниваются с константами:

```madlen
KW_ZAG:,ISO,6HЗАГОЛО   ; ЗАГОЛОВОК
KW_VET:,ISO,6HВЕТКА    ; ВЕТКА  
KW_DEI:,ISO,6HДЕЙСТВ   ; ДЕЙСТВИЕ
KW_ESL:,ISO,6HЕСЛИ     ; ЕСЛИ
KW_VYB:,ISO,6HВЫБОР    ; ВЫБОР
KW_TSI:,ISO,6HЦИКЛ     ; ЦИКЛ
KW_KON:,ISO,6HКОНЕЦ    ; КОНЕЦ
```

### 4.5. Вид иконы определяется по ключевому слову

| Вид | Иконы |
|-----|-------|
| 0 (прямоугольник) | ДЕЙСТВИЕ, КОММЕНТАРИЙ, ВАРИАНТ |
| 1 (скруглённая) | ЗАГОЛОВОК, КОНЕЦ |
| 2 (трапеция) | ВЕТКА, АДРЕС, ВЫБОР |
| 3 (шестиугольник) | ЕСЛИ, ЦИКЛ |

## 5. Соединительные линии

### 5.1. Вертикальные линии

Рисуются между иконами в одной колонке:
```
         |          (пробелы + |)          
         |
+------+ |      +------+
| текст |      | текст |
+------+       +------+
```

### 5.2. Горизонтальные линии

Рисуются после развилок (ЕСЛИ, ЦИКЛ) для выхода вправо:
```
       +------+         < условие >
       | текст |              |
   ----+      +----      ----+----
   |                ->    |
+------+            +-----+
| текст |            | Да  |
+------+            +-----+
```

## 6. Эталонный генератор разметки

**Файл:** `tools/drakon_markup.py`

Спецификация полного алгоритма:
1. **Парсинг:** Построение дерева узлов (учёт вложенности)
2. **Компоновка:** Размещение икон по колонкам (ветки слева направо)
3. **Рендеринг:** Рисование икон и соединительных линий

### Использование

```bash
# Генерация разметки
python3 tools/drakon_markup.py файл.drakon > разметка.txt

# Печать через СИПРОД
python3 tools/drakon_markup.py файл.drakon | tests/siprod/run.sh -
```

## 7. Вывод разметки *RED

Модуль DRAKON выводит текст в формате СИПРОДа:

```drakon
*RED
*RG*RU
*/*D .--------------------.
*/*D (      ЗАГОЛОВОК      )
*/*D +--------------------+
*/*D    |
*/*D   +--------------------+
*/*D  /        ВЕТКА        /
*/*D +----------------------+
*E
*END
```

### Команды разметки

- `*RED` — начало блока редактирования
- `*RG*RU` — рамка и широкий формат (128 позиций)
- `*/*D<текст>` — строка как есть (первая в карте)
- `*D<текст>` — строка как есть (продолжение)
- `*E` — конец текста блока
- `*END` — конец входного потока

## 8. Сборка

### Вариант на автокоде МАДЛЕН

Модуль собирается компилятором МАДЛЕН (Монитор-80):

```bash
mkdir /tmp/drm-work && cd /tmp/drm-work
cp drakon/drakon.madlen drakon.masm
cp ~/monitor80-re/tools/{asm.pl,cosy2txt,degak.py} .
cp /usr/local/share/besm6/2348 .
chmod +x asm.pl cosy2txt
BESM6_PATH=/tmp/drm-work:/usr/local/share/besm6 WORKVOL=2348 \
    perl -CA asm.pl drakon.masm
```
